## 五、部署操作（拿到链接的三步）

```bash
gh auth login                 # 1. 浏览器登录 GitHub
gh repo create xiao-wenhao --public --source=. --push   # 2. 建仓库并推送
gh api -X POST /repos/{owner}/xiao-wenhao/pages -f build_type=workflow  # 3. 开 Pages
```

Pages 链接形如：`https://<用户名>.github.io/xiao-wenhao/`
