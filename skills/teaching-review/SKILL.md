# 教学复盘

## 用途

教师最想知道的不是"聊了什么"，而是三件事：

1. 这个孩子**卡在哪**
2. 他是**怎么被问出来的**（哪种提问动作有效）
3. 我**下一步该从哪里教**

## 为什么不交给模型总结

模型总结看起来更流畅，但**不可复核**：它可能说"学生理解了变量的概念"，
而实际上学生只是背了一句定义。

复盘报告应该由**会话状态直接算出来**，这样每个结论都能点回学生原话。

## 三个输出块

### 1. 卡在哪里（按类型归并）

```
| 缺口类型 | 出现 | 已闭合 | 学生原话 |
| 机制不清 | 2 | 1 | 「是 8！因为 5 加 3 等于 8」 |
| 术语依赖 | 1 | 1 | 「电脑里面有内存，就记住了」 |
```

### 2. 哪种问法最有效

统计每个提问动作的**使用次数**和**逼出缺口数**，算命中率：

```
| 提问动作 | 使用 | 逼出缺口 | 命中率 |
| 给反例 | 2 | 2 | 100% |
| 请澄清 | 1 | 1 | 100% |
| 追问理由 | 2 | 0 | 0% |
```

这一块最能说明"苏格拉底法不是随便问，而是按状态换刀法"。

### 3. 下一步怎么教

- 未闭合的缺口，按类型给出建议切入点
- 费曼分数有提升的，指出"重讲有效"
- 指出本次最有效的提问动作，供教师复用

## 一句话结论

```
如果没有缺口 → 可能还需要更深的问题
如果全部闭合 → 暴露出 N 处缺口，已全部想通
否则        → 暴露出 N 处缺口，还想通了 M 处
```

## 输出格式

导出 Markdown，可直接存档、打印或放进教案：

```markdown
# 学习报告 · 变量

> 暴露出 3 处缺口，已全部想通。

共 9 轮对话。

## 卡在哪里
...

## 哪种问法最有效
...

## 下一步建议
...
```

## 注意

- 不要写成"学生表现优秀"这类评语 —— 教师需要的是**可操作**的信息
- 原话引用不要改写，改写了就失去了证据价值
- 没有数据就说"暂无"，不要编
