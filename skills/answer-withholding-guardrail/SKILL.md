# 拒答护栏

## 用途

把「AI 不给答案，只问问题」从一句口号变成**可以当场验证的数字**。

## 五项指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 答问比 Q/A | 疑问句数 ÷ 结论陈述句数 | ≥ 3 |
| 泄露率 Leak Rate | 直接给答案的轮次 ÷ 总轮次 | ≤ 5% |
| **诱导率 Leading Rate** | 把答案藏进问句的轮次 ÷ 总轮次 | ≤ 10% |
| **一问一题率** | 只含一个问号的轮次 ÷ 总轮次 | ≥ 95% |
| 缺口闭合率 Gap Closure | 已闭合缺口 ÷ 诊断出的缺口总数 | ≥ 60% |

## 为什么"诱导率"必须单独算

这是本技能最重要的一条。

把答案藏进问句（「是不是因为……所以……？」）在字面上**完全合法**：
没有结论句、以问号结尾、答问比甚至很高。
但它比直接给答案更糟 —— **学生以为自己在思考，其实只是在点头。**

普通护栏只检测"是否给了答案"，抓不到这一类。所以必须单独建一个检测器。

## 诱导式提问的判定

同时满足两个条件才算：

```
1. 问句里出现了学生还没说到的必答理解点的关键词
2. 且问句说出了该要点的"判断关系"
   —— 命中 (所以|因为…就|就会|才|说明|意思是|也就是说)
   —— 或直接断言结论 (更弱|更安全|覆盖|替换|只能记|只能表示)
```

只命中名词**不算**诱导：

| 问句 | 判定 | 理由 |
|---|---|---|
| 「你的生日，你同桌知道吗？」 | ✓ 合格 | 引入了"生日"，但没说"所以更弱" |
| 「是不是你生日同学都知道，所以更弱？」 | ✗ 诱导 | 判断关系说全了 |

## 其他三类检测

### 一问多题

按问号切句，超过 1 个问句即判违规。

### 是非问过长

「你能不能用你自己的话说说……」这类是**邀请**，不算诱导；但
「是不是因为盒子只有两个状态，所以只能记两个数？」这类是非问 + 长命题，
本质是在陈述。排除邀请句式后，是非问超过 16 字即判可疑。

### 重复提问

与上一轮问句实质相同（去标点后完全相同）即判违规。

## 分阶段要求

| 阶段 | 是否必须以问句收尾 | 原因 |
|---|---|---|
| `socratic` | **必须** | 核心承诺所在 |
| `feynman` | 否 | AI 扮演同桌，可以说「哦——我懂了！」 |
| `done` | 否 | 退场语 |

**不要对费曼阶段强求问号**，否则会把「我听懂了」误判为违规。

## 使用

```ts
import { auditAiTurn, summarize } from './guardrail'

const audit = auditAiTurn(aiText, phase, { pack, studentHits, lastQuestion })
// → { questions, declarations, qaRatio, leak, leading, multiQuestion, passed, label }

const stats = summarize(audits, gapTotal, gapClosed)
// → { qaRatio, leakRate, leadingRate, singleQuestionRate, closureRate, passRate, verdict }
```

## 实测基线

在 5 段回放脚本（变量 / 密码安全 / 二进制 / 循环 / 人工智能）共 **39 轮**对话上：

| 指标 | 实测 | 目标 |
|---|---|---|
| 答问比 | 60 – 90 | ≥ 3 ✓ |
| 泄露率 | 0% | ≤ 5% ✓ |
| 诱导率 | 0% | ≤ 10% ✓ |
| 一问一题率 | 100% | ≥ 95% ✓ |
| 闭合率 | 100% | ≥ 60% ✓ |
| 护栏通过率 | 39/39 = 100% | — |

复现命令：`pnpm selfcheck`

## 注意

- 不要为了提高答问比而让学生"多说废话"——指标服务于教学，不是反过来。
- 泄露率是最硬的一条。宁可让 AI 显得"笨一点"，也不要让它给出答案。
- 诱导率是最容易被忽略的一条。写完提问后自查一遍：**这句话里，是不是已经含有我的答案？**
