# 拒答护栏

## 用途

把「AI 不给答案，只问问题」从一句口号变成**可以当场验证的数字**。

## 三项指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 答问比 Q/A Ratio | 疑问句数 ÷ 结论陈述句数 | ≥ 3 |
| 泄露率 Leak Rate | 判定为泄露答案的轮次 ÷ 总轮次 | ≤ 5% |
| 缺口闭合率 Gap Closure | 已闭合缺口 ÷ 诊断出的缺口总数 | ≥ 60% |

## 判定流程

```
1. 切句  → 中文按 。！？；，英文按 .!?
2. 分类  → question / declaration / neutral
3. 硬泄露检测 → 命中"答案是/结果是/指的是/定义为"等模式
4. 收尾检测 → 苏格拉底阶段必须以问号收尾
5. 综合判定 → passed = 无泄露 && (阶段要求 ? 以问句收尾 : true)
```

## 分阶段要求

| 阶段 | 是否必须以问句收尾 | 原因 |
|---|---|---|
| `socratic` | **必须** | 这是核心承诺所在 |
| `feynman` | 否 | AI 扮演同桌，可以说「哦——我懂了！」 |
| `done` | 否 | 退场语 |

**不要对费曼阶段强求问号**，否则会把「我听懂了」误判为违规。

## 疑问信号

问号 `？?`，或疑问词：吗 呢 吧 什么 为什么 怎么 怎样 如何 谁 哪 多少 几个 是不是 会不会 能不能 要不要 有没有 对不对

## 结论陈述信号

- `所以 / 因此 / 总之 / 也就是说 / 答案是 / 结果是`
- `就是… / 指的是 / 意思是 / 叫做 / 称为 / 定义为`
- `它的原理是 / 原因是 / 由于`
- `第一步… 然后… 最后…`

## 硬泄露信号（最严重）

- `答案是… / 正确答案 / 结果就是 / 结果等于`
- `它(的)?(定义|概念)是 / 所谓`
- `变量是… / 循环是… / 二进制是… ` （概念名 + 判断句）

## 使用

```ts
import { auditAiTurn, summarize } from './guardrail'

const audit = auditAiTurn(aiText, phase)
// → { questions, declarations, qaRatio, leak, leakHits, endsWithQuestion, passed, label }

const stats = summarize(audits, gapTotal, gapClosed)
// → { turns, qaRatio, leakRate, closureRate, passRate, verdict }
```

## 实测基线

在 3 段回放脚本（变量 / 密码安全 / 二进制）共 **24 轮**对话上：

| 指标 | 实测 | 目标 | 状态 |
|---|---|---|---|
| 答问比 | 60 – 100 | ≥ 3 | ✅ |
| 泄露率 | 0% | ≤ 5% | ✅ |
| 闭合率 | 100% | ≥ 60% | ✅ |
| 护栏通过率 | 100%（24/24） | — | ✅ |

复现命令：`pnpm selfcheck`

## 注意

- 不要为了提高答问比而让学生"多说废话"——指标服务于教学，不是反过来。
- 泄露率是最硬的一条。宁可让 AI 显得"笨一点"，也不要让它给出答案。
